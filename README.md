## 📌 Project Overview

The Personal Resume Website is a simple, modern, and responsive portfolio website developed using HTML5 and CSS3. The purpose of this website is to present personal information, educational background, skills, projects, and contact details in a structured and visually appealing manner.

The website serves as a digital resume, allowing visitors, recruiters, and potential collaborators to learn more about my background, interests, and capabilities.

## 🛠️ Technologies Used

- **HTML5:** Used to structure the website and organize its different sections.
- **CSS3:** Used for styling, layouts, colors, spacing, animations, and responsive design.
- **Google Fonts (Poppins):** Used to create clean and modern typography.
- **Flexbox:** Used to arrange navigation links, cards, and skill elements.

## 📂 Website Sections and Their Purpose

### 1. Navigation Bar

The navigation bar is positioned at the top of the website and provides quick access to all major sections.

**Features:**
- Displays the website logo/title, "My Portfolio".
- Includes navigation links to Home, About, Education, Skills, Projects, and Contact.
- Uses a sticky positioning technique so that the navigation remains visible while scrolling.
- Includes hover effects to improve interactivity.

**Design Decision:**

A dark navy-blue background (`#172554`) was selected to establish a professional appearance and provide strong contrast against the white navigation text. The sticky navigation improves accessibility and makes movement between sections convenient.

### 2. Home / Hero Section

The hero section is the first section visitors encounter when opening the website.

**Content:**
- Welcome message.
- Personal introduction: Anik Biswas.
- Professional description: Student | Aspiring Web Developer.
- Short introduction about interests in technology and website development.
- "Explore My Profile" call-to-action button.

**Design Decision:**

A gradient background combining navy blue (`#172554`) and purple (`#5b21b6`) creates a visually engaging first impression.

The centered text layout establishes a clear visual hierarchy, while the highlighted name and call-to-action button draw attention to important information.

### 3. About Me Section

This section provides a brief introduction to my personal background, interests, and career aspirations.

**Content:**
- Interest in Business and Technology.
- Passion for learning new skills.
- Problem-solving and innovative thinking.
- Career aspirations in Business Administration and Technology.

**Design Decision:**

A white card with rounded corners and a subtle shadow is used to separate the introduction from the light background.

The centered layout keeps the content organized, readable, and visually balanced.

### 4. Education Section

The education section highlights my academic journey and qualifications.

**Information Displayed:**
- Higher Secondary Education – Krishnagar Academy, Krishnanagar, West Bengal (2025–2026).
- Bachelor in Business Administration (Digital Business and Entrepreneurship) – Indian Institute of Management Bangalore (2026–Present).

**Design Decision:**

A card-based layout is used to display educational qualifications separately.

Each card features a purple left border to visually distinguish the information. A subtle hover animation lifts the cards slightly, making the interface feel more interactive.

### 5. Skills Section

This section presents the skills and abilities I have developed or am currently exploring.

**Skills Displayed:**
- HTML
- CSS
- Communication
- Problem Solving
- Teamwork
- Music
- Leadership

**Design Decision:**

The skills are displayed as rounded badges rather than a traditional list.

A light purple background with dark purple text creates consistency with the website's overall color palette. Hover effects change the background to a darker purple, providing visual feedback.

### 6. Projects Section

The projects section showcases practical work and learning experiences.

**Projects Included:**

**Personal Resume Website**
- Developed using HTML and CSS.

**My Learning Projects**

### 7. Contact Section

This section provides visitors with ways to get in touch.

**Information Displayed:**
- Email address.

**Design Decision:**

A clean white card with rounded corners and a subtle shadow is used to present contact information.

The footer appears at the bottom of the website.

- Copyright notice.

## 🎨 Overall Design Philosophy

The website follows a minimalist, modern, and professional design approach.

The main design decisions include:

| Design Element | Purpose |
|---|---|
| Navy Blue | Establishes professionalism and trust |
| Purple Gradient | Creates visual interest and highlights important elements |
| White Cards | Improves readability and content separation |
| Rounded Corners | Creates a softer, modern appearance |
| Subtle Shadows | Adds depth without making the design cluttered |

## 📱 Responsive Design

The website incorporates responsive CSS using a media query at a maximum screen width of 768px.

The responsive adjustments include:

- Navigation elements are arranged vertically.
- Navigation links wrap and remain centered.
- The hero heading becomes smaller for mobile screens.
- Section spacing is reduced.
- Educational and project cards are arranged vertically.

These adjustments help maintain usability and readability across different screen sizes.
